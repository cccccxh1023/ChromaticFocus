# ChromaticFocus

[![Build macOS app](https://github.com/cccccxh1023/ChromaticFocus/actions/workflows/build.yml/badge.svg)](https://github.com/cccccxh1023/ChromaticFocus/actions/workflows/build.yml)

一个实验性的 macOS 显示滤镜：红通道保持清晰，绿通道轻度圆盘模糊，蓝通道使用更大的圆盘模糊，并按照显示器物理尺寸、原生像素和用户输入的观看距离换算滤镜半径。

> ChromaticFocus 不是经过验证的近视治疗，也不代表能够永久缩短眼轴。当前版本是供测试使用的 beta 版。

## 直接下载 App

**[下载 ChromaticFocus 0.1.5](https://github.com/cccccxh1023/ChromaticFocus/releases/download/v0.1.5-beta/ChromaticFocus-macOS.zip)**

不需要安装 Xcode，不需要打开终端，也不需要自己编译。

系统要求：macOS 13 或更高版本；同时支持 Apple 芯片和 Intel Mac。

## 0.1.5：色彩管理与强度模式

这一版针对“启用后整体颜色变化过大”进行了修正：屏幕捕获、Core Image、Metal 输出和覆盖窗口现在使用当前显示器的色彩配置，不再丢弃输入色彩标签后强制按固定 sRGB 输出。界面中也会显示当前检测到的色彩配置名称。

强度选项包括：

- `原图校验 · 0%`：不施加通道模糊，只检查滤镜链路能否保持原始颜色；
- `柔和模式 · 25%`；
- `适应模式 · 50%`：新版默认；
- `研究参数 · 100%`：小字和锐利界面边缘会出现更明显的彩边。

第一次测试请先使用 `原图校验 · 0%`。除实时捕获造成的轻微延迟外，整体颜色应当接近原始画面；确认后再尝试 25% 或 50%。

## 界面语言

支持：

- 跟随系统；
- 简体中文；
- English。

语言选择会被记住。主窗口、菜单栏窗口、状态提示、权限按钮和常见错误信息会立即随之切换，不需要重启 App。

## 安装

1. 下载并解压 `ChromaticFocus-macOS.zip`。
2. 完全退出并删除或移走此前安装的旧版 `ChromaticFocus.app`。
3. 把新版 `ChromaticFocus.app` 拖入“应用程序”。
4. 双击 App 尝试打开一次。
5. 如果 macOS 提示无法验证开发者或无法检查恶意软件：进入“系统设置 → 隐私与安全性”，向下滚动，在安全性区域点击“仍要打开”，然后再次确认。
6. 允许“屏幕与系统音频录制”权限；授权后可能需要退出并重新打开 App。

启动时会直接显示普通主窗口，同时也会显示 Dock 图标和屏幕右上角的菜单栏眼睛图标。

## 基本使用

1. 在窗口顶部选择界面语言。
2. 选择需要处理的显示器。
3. 输入眼睛到屏幕的大致距离。
4. 先选择 `原图校验 · 0%` 检查颜色。
5. 再尝试 `柔和模式 · 25%` 或 `适应模式 · 50%`。
6. 点击“启用滤镜”。

紧急关闭快捷键：`Control–Option–Command–R`（`⌃⌥⌘R`）。

## 自动调节

程序会自动读取显示器的原生像素、Retina 缩放、物理尺寸、旋转状态和色彩配置，并在显示器或色彩配置发生变化时重新读取参数。电脑无法自动知道眼睛到屏幕的实际距离，因此观看距离需要由用户输入一次。外接显示器报告的物理尺寸异常时，可以手动填写显示器宽度。

## 隐私

- 不捕获音频；
- 不保存截图或录屏；
- 不上传屏幕画面；
- 不包含分析、广告或第三方跟踪；
- 屏幕帧只在本机内存和 GPU 中实时处理。
